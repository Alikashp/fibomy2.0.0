# Продукт: требования владельца

Ответы владельца продукта, зафиксированные 2026-09-26. Формулировки сведены в структуру, смысл не менялся.

## Платформа и аудитория

- **Платформа:** только Telegram-бот. Веб не планируется.
- **Целевая аудитория:** сейчас в основном студенты и преподаватели. Стратегически — переход к корпоративным сотрудникам; это нужно закладывать в архитектуру уже сейчас.
- **Типовые сценарии:** доклады, презентации проектов и результатов.
- **Языки:** до 15 самых распространённых, включая русский и языки СНГ. Решается через промпт LLM.

## Монетизация и интеграции

- **Модель:** подписки. Пока не включены.
- **API:** нужно закладывать — сервис будет подключаться к другому боту. Правки отдельных слайдов через API не нужны.

## Нагрузка и скорость

- **Объём:** ~1 000 генераций в месяц в первые месяцы, ~10 000 в месяц через полгода.
- **SLA:** не более 2 минут от нажатия кнопки до файла у пользователя. Время ожидания в очереди не считается.
- **Хостинг:** Railway.

## Что получает пользователь

- **Результат:** одна презентация (не несколько вариантов на выбор).
- **Количество слайдов:** выбирает пользователь, от 4 до 20.
- **Выходные форматы:** PDF и редактируемый PPTX с нативными объектами — таблицы и графики должны быть нативными, не картинками.
- **Правки после генерации:** нужны в самом боте. В API пока не нужны.
- **Свой шаблон / брендинг пользователя:** не нужен.
- **Вотермарк «Fibonacci.»:** только на бесплатном тарифе.

## Входные данные

- **Форматы:** тема, текст, файлы pptx / docx / pdf / txt.
- **Обязательное требование:** цифры и данные из входных документов обязательно превращаются в графики, таблицы, диаграммы.

## Картинки

На выбор пользователя:
- из интернета — только с легальными лицензиями;
- генерация через siliconflow.com, модель z-turbo.

## Модели

- **LLM:** OpenAI — gpt-5_6-luna или менее мощная.
- **Картинки:** siliconflow, z-turbo.

## Качество

- **Аудит качества:** на этапе разработки шаблонов и в тестах.
- **На проде:** только быстрые детерминированные автоисправления (без дополнительных «проверяющих» вызовов).

## Ключевая продуктовая задача

Уйти от одинаковых слайдов. Для каждого типа контента (числа, текст, процесс, сравнение и т.д.) — пул из 4–5 вариантов представления, плюс цветовые темы поверх, чтобы презентации не были похожи друг на друга.
