# 01. Объём фазы 1

**Статус:** утверждено владельцем и техлидом 01.10.2026 (с правками: четыре темы, временная маршрутизация, порог темы 200 знаков) · **Дата:** 30.09.2026, правка 01.10.2026 · **Опирается на:** ТЗ (разделы 1.5, 3, 4, 9), `docs/SPIKE_PPTX.md`, D-001…D-030

Фаза 1 — новый движок генерации, который **целиком заменяет старый** (D-026). Бот получает PPTX и PDF, собранные из нативных объектов, с вариантами слайдов и четырьмя темами. Всё, что здесь не названо, в фазу 1 не входит (раздел 3).

---

## 1. Что получает пользователь в конце фазы 1

- Тот же бот и тот же диалог со сводкой (D-023). В сводке «Дизайн» — четыре темы нового движка вместо четырёх цветовых схем старого.
- После генерации приходят **два файла**: PPTX (редактируемый) и PDF (конвертация того же PPTX) — всем пользователям, в том числе на бесплатном тарифе (вопрос 2, D-040).
- Слайды одного типа контента выглядят по-разному: вариант выбирает код, у ключевых типов 2–3 варианта.
- Числа из таблиц документа превращаются в нативные диаграммы, которые открываются как диаграммы («Изменить данные» в PowerPoint).
- Всё, что умел старый движок, сохраняется: доклад по теме и по материалу (`strict` / `extend`), питч-дек, картинки, ФИО и группа на титуле, водяной знак на бесплатном тарифе.

## 2. Что входит

### 2.1 Пайплайн
INGEST → OUTLINE → SELECT → CONTENT → IMAGES → FIT → RENDER → CONVERT → DELIVER — полностью, с деградацией на каждом этапе (`03_ARCHITECTURE.md`).

### 2.2 Входы

| Вход | Фаза 1 | Отличие от старого движка |
|---|---|---|
| Тема (3–200 знаков) | да | тема ставится на титул **дословно** кодом (G-05). Сообщение длиннее 200 знаков — текст-материал (было 300; вопрос 8, D-039) |
| Текст в сообщении | да, до 30 000 знаков | было 15 000 |
| .docx | абзацы + **таблицы как наборы данных** | таблицы шли плоским текстом |
| .pdf (до 50 страниц) | текст + таблицы (`find_tables`) как наборы данных; скан без текста — понятная ошибка | было 40 страниц |
| .pptx | текст, заметки, **таблицы и данные нативных диаграмм** | таблицы и диаграммы не читались |
| .txt | да, chardet | без изменений |
| Длинный документ | до 40 000 знаков — целиком; больше — начало документа и **явное предупреждение**, сколько не вошло | было: молча обрезалось до 15 000 |

Параллельная выжимка частей длинного документа (ТЗ 3.1) — фаза 2. Структура `SourceDigest` под неё заложена сразу (`04_CONTRACTS.md`, 3).

### 2.3 Типы презентаций

| Тип | Сюжет (storyline) | Примечание |
|---|---|---|
| Доклад по теме | объяснение темы: где встречается → части темы с примерами → заблуждения → выводы | как `narrative_topic.txt` сейчас |
| Доклад по материалу | по жанру источника: `report`, `requirements`, `plan`, `article`, `other` | как `narrative_text.txt` сейчас (жанры ТЗ 4.8.1) |
| Питч-дек | проблема → решение → почему сейчас → рынок → модель → трекшн → конкуренты → команда → роадмап → запрос | на kinds фазы 1, см. таблицу ниже; число слайдов фиксировано (11), кнопки «Сменить число слайдов» в сводке у питч-дека нет |

Питч-дек на kinds фазы 1 (вопрос 3 в `10_OPEN_QUESTIONS.md`, утверждено):

| Блок питч-дека | kind фазы 1 |
|---|---|
| проблема, решение | `statement` (с картинкой, если есть) или `bullets` |
| почему сейчас | `bullets` |
| рынок TAM/SAM/SOM | `metrics` (3 числа, расчёт — в подписи, D-025) |
| бизнес-модель | `comparison` или `bullets` |
| трекшн | `metrics` |
| конкуренты | `comparison` (мы / альтернативы) — таблица сравнения появится с kind `table` в фазе 2 |
| команда | `bullets` (карточки) |
| роадмап | `process` (этапы без дат) — `timeline` с датами в фазе 2 |
| запрос / контакты | `statement` (роль `ask`) + `closing` |

### 2.4 Типы контента и варианты

10 kinds, 22 варианта. Геометрия, вместимость и вайрфреймы — `05_LAYOUTS.md`.

| kind | Варианты фазы 1 | Запасной (самый вместительный) |
|---|---|---|
| `title` | `cover_center`, `cover_band`, `cover_split_image` | `cover_center` |
| `statement` | `big_quote`, `highlight_band`, `statement_image` | `big_quote` |
| `bullets` | `icon_list`, `cards_grid`, `numbered_columns` | `cards_grid` |
| `comparison` | `two_columns`, `pros_cons` | `two_columns` |
| `process` | `horizontal_steps`, `chevrons`, `vertical_steps` | `vertical_steps` |
| `metrics` | `big_number`, `kpi_cards` | `kpi_cards` |
| `chart_series` | `column_chart`, `line_chart` | `column_chart` |
| `chart_share` | `donut` | `donut` (при неприменимости — `metrics` или `bullets`) |
| `conclusion` | `numbered_takeaways`, `cards` | `numbered_takeaways` |
| `closing` | `thanks_center` | `thanks_center` |

Кроме kind, у слайда есть **роль** (`role`): `ask` (запрос, решение, призыв), `goal`, `results`, `details` и др. Роль не меняет макет напрямую, но влияет на приоритет при нехватке слайдов и на выбор варианта (G-04: запрос — `statement.highlight_band`, последний содержательный слайд). Список ролей — `04_CONTRACTS.md`, 4.1.

### 2.5 Темы
Четыре темы (D-037): `graphite_light`, `graphite_dark` и две яркие — `azure_coral` (синяя с коралловым акцентом) и `fresh_green` (свежая зелёная). Шрифт Arial (D-027), контраст всех используемых пар ≥ 4.5:1, цвета диаграмм чистые и попарно различимые (`05_LAYOUTS.md`, 6). В сводке бота — «☀️ Графит светлая», «🌙 Графит тёмная», «🌊 Лазурь», «🌿 Свежая зелёная»; все темы доступны всем (вопрос 12). Выбор тем в боте — с сессии 2 (перенесено владельцем из сессии 3); требования к цвету слайдов — `05_LAYOUTS.md`, 8 (сессия 3).

### 2.6 Картинки
- Режимы `none` и `web`. Источник `web` — Pexels (D-006) с подписью автора в колонтитуле и списком источников в заметках последнего слайда.
- Слоты картинок есть у двух вариантов: `title.cover_split_image` и `statement.statement_image`. Не больше одной картинки на два слайда.
- Картинка не нашлась или не скачалась за таймаут — выбирается вариант без картинки.
- ИИ-картинки (SiliconFlow) — фаза 2.

### 2.7 Выход
- **PPTX:** нативные текстовые поля, фигуры, диаграммы. Иконки — PNG из Tabler Icons. Автоподбор размера выключен, тени у фигур удалены (находки спайка 1, 5). Метаданные: заголовок, автор = пользователь, приложение = Fibonacci AI.
- **PDF:** LibreOffice headless из того же PPTX (D-001).
- **Водяной знак** «Fibonacci.» — только в колонтитуле PDF на бесплатном тарифе. В PPTX его нет: удаляется одним кликом, защищать им PPTX бессмысленно (ТЗ 3.9). PPTX в фазе 1 — всем (вопрос 2, D-040); ограничение PPTX тарифом — вместе с подпиской в фазе 3.

### 2.8 Бот
- Диалог со сводкой без изменений, кроме списка тем.
- Прогресс генерации — правка одного статусного сообщения по этапам (`02_CJM.md`).
- После выдачи: «🔁 Повторить с другими параметрами» (сводка с теми же параметрами) и «🆕 Новая презентация».
- Языки — как сейчас: ru, en, uz, kk (вопрос 15). Расширение до 15 — фаза 2 (hy и ka ждут шрифта-подстановки, D-027).
- До сессии 3 питч-дек обслуживает старый движок — временная маршрутизация (D-038, `08_MIGRATION.md`, 2.1); материал — новый движок с сессии 2.

### 2.9 Хранение и наблюдаемость
- Каждая колода — строка в новой таблице `decks` с полным `DeckSpec` (JSONB), параметрами запроса, длительностями этапов, токенами и стоимостью.
- Файлы — в S3 на 30 дней, если хранилище настроено (вопрос 5): Cloudflare R2 или любое S3-совместимое (Yandex Object Storage, Selectel); код от провайдера не зависит (D-042).
- JSON-логи с `deck_id` и `stage` на каждой строке.

### 2.10 Тесты и CI
Юнит-тесты, стресс-галерея макетов в CI, golden G-01…G-05 + питч-дек на новом движке, проверка открытия PPTX (`07_TESTING.md`).

## 3. Что не входит

| Не входит | Где будет | Что происходит в фазе 1 |
|---|---|---|
| kinds `table`, `timeline`, `agenda`, `section`, `image_focus` | фаза 2 / 4 | план их не предлагает: схема OUTLINE знает только 10 kinds фазы 1. Этапы с датами — `process` с датой в названии шага; таблица объектов × атрибутов — `chart_series` (если числа) или `bullets` |
| Ещё 2 темы (всего 6), теги тем и `auto` | фаза 2 | выбор из четырёх тем |
| ИИ-картинки | фаза 2 | только `none` / `web` |
| Выжимка длинного документа по частям | фаза 2 | начало документа + предупреждение |
| Диаграммы bar, stacked, pie; больше 3 серий | фаза 2 | 1–3 серии, column / line / donut |
| Сравнение 3 объектов | фаза 2 (`comparison_table`) | 3 объекта → `bullets.cards_grid` |
| Проверка чисел по `source_ref` с перегенерацией слайда | фаза 1 — проверка и деградация; перегенерация по ошибке факта — да, 1 попытка | — |
| VLM-аудит | фаза 2 | только детерминированные проверки |
| REST API | фаза 3 | контракт описан (`04_CONTRACTS.md`, 7), модели данных ему соответствуют |
| Правки слайдов в боте | фаза 4 | `DeckSpec` хранит всё нужное (`04_CONTRACTS.md`, 5) |
| Текст выступления в заметках | v1.x | в заметках только источники картинок |
| Новые тарифы, подписка, лимиты на сервере | фаза 3 | текущие лимиты (2 бесплатных колоды) |
| 15 языков, RTL | фаза 2 / потом | ru, en, uz, kk |
