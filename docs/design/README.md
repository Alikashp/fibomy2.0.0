# docs/design — проект нового движка (фаза 1)

Документы `01…10` написаны **до кода** (30.09–01.10.2026) и описывают, как движок задуман. Часть задуманного сделана иначе или ещё не сделана. Поэтому у каждого документа ниже — статус соответствия коду и известные расхождения.

**Как устроено сейчас — `README.md` в корне репозитория.** При расхождении документа с кодом прав код: документ правится в той же задаче, где расхождение найдено (D-080). Требования (что должно быть) задаёт `docs/TZ.md`.

## Статусы

| Статус | Значит |
|---|---|
| **соответствует коду** | Описывает код как он есть; расхождение — ошибка документа |
| **проект, частично сделан** | Сделанное совпадает с кодом, кроме перечисленного ниже; остальное — план |
| **черновик, правда — в файлах** | Источник истины — файлы, на которые ссылается документ (YAML, промпты); документ — пояснение |
| **план** / **закрыт** | История решений; текущее состояние — в `docs/PROGRESS.md` |
