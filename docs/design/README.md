# docs/design — проект нового движка (фаза 1)

Документы ниже написаны **до кода** (30.09–01.10.2026) и описывают, как движок задуман. Часть задуманного сделана иначе или ещё не сделана. Поэтому у каждого документа — статус соответствия коду и известные расхождения.

Удалены 06.11.2026 (D-083), история — в git: `03_ARCHITECTURE` — его заменил `docs/ARCHITECTURE.md` (как есть в коде); `07_TESTING` — слит в `docs/features/quality.md`; `08_MIGRATION` и `09_PLAN` — их остаток в `docs/ROADMAP.md`; `10_OPEN_QUESTIONS` — ответы целиком в ТЗ 11.1.

**Как устроено сейчас — `docs/ARCHITECTURE.md`, что дальше — `docs/ROADMAP.md`.** При расхождении документа с кодом прав код: документ правится в той же задаче, где расхождение найдено (D-080). Требования (что должно быть) задаёт `docs/TZ.md`.

## Статусы

| Статус | Значит |
|---|---|
| **соответствует коду** | Описывает код как он есть; расхождение — ошибка документа |
| **проект, частично сделан** | Сделанное совпадает с кодом, кроме перечисленного ниже; остальное — план |
| **черновик, правда — в файлах** | Источник истины — файлы, на которые ссылается документ (YAML, промпты); документ — пояснение |
