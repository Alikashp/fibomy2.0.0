# ИИ-картинки

**Назначение:** картинки на титуле и нескольких слайдах, сгенерированные по смыслу слайда (SiliconFlow, модель Z-Image-Turbo, D-067).

## Как работает

1. **Каким слайдам нужна картинка** решает `core.pipeline.plan_images`: титул (запрос `deck.cover_image_query` или первый `image_query` плана), затем слайды с `image_query` подходящих kinds, не подряд и не слайд-запрос. Всего не больше `per_deck` из конфига.
2. **Промпт** = смысл слайда (`image_query` плана) + внешность людей по языку колоды (`appearance.yaml`) + стиль темы и общие правила (`style.yaml`: фотореализм, без текста и логотипов). Хвост промпта одинаков у всех картинок колоды — единый стиль.
3. **Генерация идёт параллельно с CONTENT** (`core.images.start`): задачи стартуют после SELECT, не больше `concurrency` одновременно, у каждой свой таймаут. После CONTENT пайплайн забирает готовые (`_collect_images`). Не успела или ошибка — слайд переключается на вариант без картинки того же kind, колода не ждёт.
4. **Обработка файла:**
   - картинка заказывается выше слота (`image_size`);
   - полоса с надписью провайдера «AI 生成» срезается по правилу `marking.crop_px` (D-079);
   - файл обрезается по центру под пропорции слота, сжимается в JPEG и встраивается в PPTX.
5. **Стоимость** — этап `images` в `decks.usage` и `decks.cost_rub`: `price_usd` × `USD_RUB_RATE`. Картинка, которая не успела, не оплачивается в учёте.

## Где в коде

- `src/core/images/__init__.py` — запуск, запрос к SiliconFlow, `strip_marking`, `cover_crop`, цена.
- `src/core/pipeline.py` — `plan_images`, `_collect_images`.
- Параметры: `prompts/v2/images/config.yaml` (модель, размер, число на колоду, таймаут, параллельность, цена, правило обрезки), `style.yaml`, `appearance.yaml`.
- Переменные: `SILICONFLOW_API_KEY` (без ключа колоды собираются без картинок), `SILICONFLOW_BASE_URL`, `SILICONFLOW_MODEL`, `IMAGES_PER_DECK` — в `.env.example`.
- Зонд надписи и картинки «до / после» — `scripts/probe_siliconflow_watermark.py`, workflow `siliconflow-probe`; примеры — `docs/design/review/siliconflow/`.

## Нюансы

- **Внешность людей указывается в промпте всегда:** ru, en — европейская; kk, uz — центральноазиатская. Без указания модель рисует людей азиатской внешности.
- **Надпись провайдера одного размера в пикселях при любом разрешении** и всегда в правом нижнем углу. Поэтому правило обрезки — в пикселях, а запас по высоте заказан заранее. Сменит провайдер позицию — запустить зонд (режим `marking`) и поправить `crop_px`, код не трогать.
- **Кадрирование идёт после среза полосы**, иначе cover-crop вернул бы надпись в кадр.
- **Кэша картинок нет:** промпт уникален для слайда, попаданий почти не было бы.
- **В API картинки отключаются** полем `image_mode: none` (`docs/API.md`); в боте они всегда включены. В golden картинки заказывают только G-05 и G-06 (`quality.md`).
- **Пометки «Изображения сгенерированы ИИ» в заметках слайда нет** — убрана по решению владельца (D-079).
